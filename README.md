# Chicken Genes for AI

Can animal-breeding math predict when fine-tuning makes an AI model go bad?

An experiment that applies quantitative genetics (the G-matrix, the breeder's equation, evolvability) to emergent misalignment in Qwen2.5-0.5B-Instruct, run on one laptop GPU.

**Read it:** https://cuuper22.github.io/chicken-genes/

The page is a single self-contained `index.html` in the CuperOS style.
